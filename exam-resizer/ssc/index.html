Client-Side Privacy Policy

This application is engineered as a 100% client-side web utility. When you select a photo, signature, or document, it is rendered strictly inside your device's memory using standard HTML5 Canvas APIs.


Zero Network Uploads: No photos, personal names, dates, or documents are ever transferred to or processed on external servers. You can safely disconnect your internet and continue using this tool offline.
